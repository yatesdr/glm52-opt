# PR #84 KLD comparison — final n=3 report

Date: 2026-07-27

## Result

The matched three-run comparison did not find a large shallow
distribution-level regression from `oldest_boundary`.

| Policy | Runs | Mean `KL(BF16 reference || candidate)` ± SD | Min | Max |
|---|---:|---:|---:|---:|
| `exact` | 3 | 0.15823696 ± 0.00468419 | 0.15539664 | 0.16364348 |
| `oldest_boundary` | 3 | 0.16044075 ± 0.00297924 | 0.15700885 | 0.16236257 |

Paired `oldest_boundary - exact` deltas were:

```text
-0.00663463
+0.00655420
+0.00669180
```

The mean paired delta was `+0.00220379`, or `+1.39%` of the exact-policy
mean. Its sample SD was `0.00765461`, and one of the three paired deltas
favored `oldest_boundary`. At n=3, this is a noisy, small difference and
does not establish a policy-caused KLD change.

## Test contract

All six runs used:

- image:
  `glm52-serve:v20-20260726-oldest-boundary-pr-candidate`
- image identity:
  `sha256:43e5a48781ee5cf40a92cc494749b21306b72280bd1a875721a45422323f2599`
- GLM-5.2 NF3 hybrid checkpoint
- `nvfp4_nf3_hybrid` weight quantization with online `nf3-mxfp8`
- `nvfp4_ds_mla` KV cache with FP8 RoPE
- TP4/DCP1, eager execution
- 2,048 identical input token IDs and 2,047 compared output positions
- the same pinned BF16 reference logits
- KLD direction `KL(BF16_reference || candidate)`

Each policy ran three times. The aggregator failed closed on changes to the
image, reference, runner, token IDs, context length, model path, quantization,
KV format, TP/DCP posture, eager setting, memory utilization, and batched-token
limit. It also required exactly runs 1–3 for each policy and unique raw-log
hashes.

## Scope limitation

This is a valid 2,048-token image-level no-regression gate, but it is not a
selector-sensitive test. The selector budget is also 2,048, so every eligible
token is selected under both policies. The result checks the complete image
and inference path for an obvious distribution regression; it does not measure
the policy's effect when the candidate set exceeds the selector budget.

The frozen 350k reproducer and randomized 50k–475k ladder supply the current
end-to-end evidence for deep-context behavior. A permanent scorer/selector fix
needs a separate long-context or captured-activation comparison against the
reference scorer.

## Runner teardown

The original KLD runner occasionally segfaulted after writing a complete valid
result during interpreter/CUDA teardown. The final matrix used an explicit
cleanup-only patch. It does not alter tokenization, model execution, logits, or
KLD calculation. All six runs exited cleanly and emitted the fail-closed
completion marker.
